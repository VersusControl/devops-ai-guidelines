## Additional Resources

- **This book's code** — every chapter has a self-contained folder under
  `code/`, with a README, tests, and recorded fixtures. Start with
  `code/chapter-09/` for the benchmark and `code/chapter-11/` for the CI gate.
- **Versus Incident** — the open-source SRE agent used as this book's running
  example:
  [github.com/VersusControl/versus-incident](https://github.com/VersusControl/versus-incident)
  · [docs.versusincident.com](https://docs.versusincident.com)
- **TypeSafe AI and Jev** — the typed-decision model family used for the
  explanation judge:
  [docs.typesafe.ai/introduction](https://docs.typesafe.ai/introduction)
- **Cloudflare Workers AI model catalog** — where the book calls Jev, and where
  model names and availability live:
  [developers.cloudflare.com/workers-ai/models](https://developers.cloudflare.com/workers-ai/models/)
- **OpenAI function calling** — the tool-call contract behind the agent in
  Chapters 1 and 8:
  [platform.openai.com/docs/guides/function-calling](https://platform.openai.com/docs/guides/function-calling)
- **GitHub Actions** — the CI system used for the gate in Chapter 11:
  [docs.github.com/en/actions](https://docs.github.com/en/actions)
- **Wilson score interval** — the small-sample interval used in the benchmark
  reports:
  [en.wikipedia.org/wiki/Wilson_score_interval](https://en.wikipedia.org/wiki/Wilson_score_interval)
- **Building effective agents** — Anthropic's practical guide to agent patterns,
  useful when deciding what your harness should even measure:
  [anthropic.com/engineering/building-effective-agents](https://www.anthropic.com/engineering/building-effective-agents)
